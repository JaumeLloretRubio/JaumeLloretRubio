<summary><code>$ cat ~/method.md</code>&ensp;<sub><b>&#9656; c&#243;mo investigo &#183; kill-driven, pre-registrado / how I research</b></sub></summary>

<br>

```console
[01]  AISLAR EL RIESGO PORTANTE
      Una sola pregunta decide el proyecto. Se responde antes de
      construir nada encima.
      Isolate the load-bearing risk. Kill before you build.

[02]  PRE-REGISTRO CERRADO
      Baseline fuerte, métrica no amañable y kill bilateral —qué
      confirma y qué refuta— fijados antes de tocar código.
      Closed pre-registration: strong baseline, non-gameable metric,
      two-sided kill criteria, all fixed up front.

[03]  ASIMETRÍA AL INTERPRETAR
      Un kill bien anclado vale tal cual. Un positivo no se cree
      hasta sobrevivir al control de confound, a la escala y al
      gate de validez.
      A well-anchored kill stands. A positive must survive
      confound control, scale and the validity gate.

[04]  UN NULL ES UN RESULTADO
      Un null pre-registrado se documenta y se propaga; ahorra
      meses construidos sobre cimientos inexistentes.
      A pre-registered null is a result, not a failure.
```

</details>
